## 1. SLEEPING EXECUTIVE CONTINUATIONS

THE EXECUTIVE AREA MUST REMAIN SAFE WHEN A USER EXTENT MOVES OR IS SWAPPED.
THE CURRENT STABLE U-AREA DESIGN IS CORRECT AND TESTED.  REOPEN IT ONLY IF A
MEASURED USERLAND WORKLOAD JUSTIFIES THE COMPLEXITY.

- IDENTIFY EXACTLY WHICH WORDS MUST REMAIN RESIDENT FOR A SLEEPING PROCESS.
- PROVE WHICH STACK FRAMES MAY BE LIVE ACROSS PROC_WAIT_EVENT.
- CHECK WHETHER ALL SLEEPABLE PATHS NEED THE SAME MAXIMUM STACK RESERVATION.
- DO NOT COPY OR RECONSTRUCT ARBITRARY C STACKS AS A WORKAROUND.
- PRESERVE STABLE PHYSICAL EXECUTIVE CONTINUATIONS UNTIL A BETTER DESIGN IS
  PROVEN CORRECT, SMALLER, AND NO SLOWER.

## 2. EXECUTIVE-AREA MEASUREMENTS

CURRENT REGRESSIONS ALREADY COVER PIPE BLOCK/WAKEUP, WAIT/CHILD EXIT, REAL
SWAP/RESUME, USER-EXTENT COMPACTION, STOP/CONTINUE, AND STACK WATERMARKS.
FUTURE MEASUREMENTS SHOULD CONCENTRATE ON CASES CREATED BY NATIVE USERLAND:

- MAXIMUM FILE-DESCRIPTOR USE.
- DEEPEST VFS/FILESYSTEM CALL PATHS REACHED BY DSH, MAKE, DAS, AND ELVIS.
- REPEATED RUN/EXEC/WAIT/EXIT UNDER NATIVE BUILD LOAD.
- TTY/JOB-CONTROL STACK DEPTH UNDER INTERACTIVE DSH USE.

DO NOT REDUCE THE CURRENT 0310-OCTAL PRIVATE KERNEL STACK WITHOUT A NEW
WATERMARK MEASUREMENT WITH A REAL SAFETY MARGIN.

## 3. NEXT GENERAL RESIDENT SWEEP

THE 2026-09-14 GCC PRE-USERLAND SWEEP REACHED 12277 DECIMAL WORDS OF KCORE
PLUS NORMAL FULL-BOOT MRES.  THE CURRENT KCC WORK USES 13 KIWORDS, 13312
DECIMAL WORDS, AS AN OPTIMIZATION GOAL RATHER THAN A HARD ACCEPTANCE CEILING;
THE GCC GOAL REMAINS 12 KIWORDS, 12288 WORDS.  A LARGE COMMON-PATH EXECUTION
GAIN MAY JUSTIFY A SMALL RESIDENT INCREASE, AND STRUCTURAL RAM REDUCTIONS REMAIN

DO NOT START ANOTHER UNFOCUSED KERNEL SWEEP MERELY TO CREATE UNUSED HEADROOM.

SPECIFIC KERNEL NEED.  SELECTIVE PDP-10 ASSEMBLY REMAINS APPROPRIATE ONLY FOR
LARGE, BOUNDED, DIRECTLY TESTABLE ROUTINES AFTER STRUCTURAL C SAVINGS ARE
EXHAUSTED.

## 4. DEFERRED SWAP OPTIMIZATION

THE CURRENT CORRECTNESS FORMAT SWAPS THE COMPLETE ROUNDED USER IMAGE IN NORMAL
0200-WORD DISK SECTORS.  CLEAN EXECUTABLE-TEXT RELOAD MAY BE REVISITED ONLY
AFTER NATIVE PROGRAM MEASUREMENTS SHOW THAT THE EXTRA COMPLEXITY SAVES USEFUL
RAM OR I/O.  SLOT-0 SWAP SERVICE MUST NOT DEPEND ON A SLEEPING FILESYSTEM
PROVIDER.

## 5. USERSPACE OVERLAY MEASUREMENT

DO NOT DEFINE AN OVERLAY ABI BEFORE NATIVE DAS AND ELVIS EXIST.  MEASURE THEIR
REAL WORKING SETS FIRST.  OVERLAYS ARE A USERSPACE MEMORY OPTIMIZATION, NOT A
PRE-USERLAND COMPLETION REQUIREMENT.

## 6. MEASUREMENT AND ACCEPTANCE

FOR EVERY PROPOSED RESIDENT-MEMORY CHANGE:

- REPORT SIZES IN OCTAL AND DECIMAL PDP-10 WORDS.
- MEASURE THE FULL KCORE + MRES TOTAL, NOT JUST THE TOUCHED OBJECT.
- RUN THE RELEVANT MRES SIZE GUARD AND TARGET/SYSTEM REGRESSIONS.
- PRESERVE ASSEMBLER/COMPILER CORRECTNESS AS THE HIGHEST-PRIORITY GATE.
- REJECT CHANGES WHICH ADD COMMON-CASE TRAPS OR COPIES MERELY TO SAVE RAM.
- REJECT SOURCE-SHARING REFACTORS WHICH INCREASE LINKED RESIDENT SIZE.
