## 7. REAL INIT, LOGIN, AND MULTI-TERMINAL BOOTSTRAP - COMPLETE

THE REAL USERSPACE BOOTSTRAP IS IMPLEMENTED AND ACCEPTED.
THE TEMPORARY DSH-AS-INIT BOOT PATH HAS BEEN REMOVED.  THE REQUIRED PROCESS
CHAIN IS:

'''TEXT
KINIT
  -> /SYSTEM/INIT                 PID 1 / ORPHAN REAPER
       -> /SYSTEM/EXEC/LOGIN 0    CTY
       -> /SYSTEM/EXEC/LOGIN 1    DCS0
       -> /SYSTEM/EXEC/LOGIN 17   GE0
            -> EXEC CONFIGURED SHELL, INITIALLY /SYSTEM/EXEC/DSH
'''

INIT MUST REMAIN SMALL: READ `/CONFIG/INITTAB`, START `RESPAWN` OR `ONCE`
ENTRIES, WAIT FOR ANY CHILD, REAP ADOPTED ORPHANS, AND RESPAWN A LOGIN ONLY
AFTER THE CORRESPONDING CHILD REALLY EXITS.  STOP/CONT NOTIFICATIONS MUST NOT
CREATE DUPLICATE LOGIN PROCESSES.  DO NOT TURN INIT INTO A SERVICE MANAGER.

LOGIN RECEIVES A LOGICAL TTY NUMBER, CREATES THE LOGIN SESSION/PROCESS GROUP,
CLAIMS THAT CONTROLLING TTY, MAKES ITS PGRP FOREGROUND, AND USES THE EXISTING
FD0/FD1/FD2 CONTROLLING-TTY STREAMS.  IT AUTHENTICATES AGAINST
`/CONFIG/PASSWD`, SETS GID THEN UID, CHANGES TO THE ACCOUNT HOME DIRECTORY, AND
EXECUTES THE CONFIGURED SHELL.  LOGIN DOES NOT REMAIN RESIDENT AFTER SUCCESS.

VERSION 0.9 PASSWORD POLICY IS DELIBERATELY TEMPORARY: `/CONFIG/PASSWD` STORES
THE PASSWORD FIELD IN CLEARTEXT.  AN EMPTY PASSWORD FIELD LOGS IN WITHOUT A
PASSWORD PROMPT; A NONEMPTY FIELD IS PROMPTED WITHOUT ECHO AND COMPARED
DIRECTLY.  A BETTER PASSWORD VERIFIER IS DEFERRED.

THE INITIAL NATIVE INSTALLATION TREE IS:

'''TEXT
/SYSTEM/INIT
/SYSTEM/EXEC
/SYSTEM/LIB
/SYSTEM/INCLUDE
/SYSTEM/MANUAL
/SYSTEM/SOURCE
/OPTION/EXEC
/OPTION/LIB
/OPTION/INCLUDE
/OPTION/MANUAL
/OPTION/SOURCE
/CONFIG/INITTAB
/CONFIG/PASSWD
'''

`/SYSTEM` IS THE BASE SYSTEM.  `/OPTION` IS THE PARALLEL TREE FOR
NON-SYSTEM/OPTIONAL SOFTWARE.  `/CONFIG` IS THE REAL SYSTEM-CONFIGURATION
DIRECTORY, ANALOGOUS IN ROLE TO UNIX `/ETC`.

SIMH MAY EXPOSE SERIAL TERMINALS THROUGH HOST TCP/TELNET WITHOUT ADDING A
DAIMOS NETWORK STACK.  THE INITIAL TEST CONFIGURATION IS DCS0 ON TCP 1101 AND
GE0 ON TCP 1201.  THIS DOES NOT CHANGE THE VERSION 0.9 NETWORKING DEFERRAL.

KERNEL PREREQUISITES FOR THIS BOOTSTRAP ARE REAL UID/GID CREDENTIALS, D6FS/VFS
OWNER/GROUP/OTHER ACCESS CHECKS, GENERIC LOGICAL-TTY INPUT/OUTPUT AND
FOREGROUND-JOB-CONTROL ROUTING, AND TRUE EXEC IMAGE REPLACEMENT.

TEST AT LEAST:

- `/SYSTEM/INIT`, `/SYSTEM/EXEC/LOGIN`, AND `/SYSTEM/EXEC/DSH` ARE DISTINCT
  IMAGES.
- BOOT ENTERS INIT AS PID 1.
- INIT PARSES VALID INITTAB RECORDS AND SAFELY REJECTS MALFORMED RECORDS.
- CTY, DCS0, AND GE0 EACH RUN INDEPENDENT LOGIN/DSH SESSIONS.
- SIMH DCS0:1101 AND GE0:1201 BOTH REACH LOGIN AND DSH.
- LOGIN DROPS TO THE CONFIGURED UID/GID AND ENTERS THE CONFIGURED HOME.
- EMPTY PASSWORD ACCOUNTS SKIP THE PASSWORD PROMPT; NONEMPTY PASSWORDS DO NOT
  ECHO INPUT.
- DSH EXIT IS REAPED AND LOGIN IS RESPAWNED.
- ORPHANED CHILDREN ARE ADOPTED AND REAPED BY INIT.
- STOP/CONT DOES NOT CREATE A SECOND LOGIN ON THE SAME TTY.
- REPEATED LOGIN/LOGOUT DOES NOT LEAK PROCESS SLOTS, FILE DESCRIPTORS, U-AREAS,
  OR SWAP BACKING.
- FOREGROUND JOB CONTROL ON ONE TTY DOES NOT AFFECT INIT OR ANOTHER TTY.

SECTION 7 PASSED ITS ACCEPTANCE GATE ON 2026-09-16.  VERIFIED COVERAGE
