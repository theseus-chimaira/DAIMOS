## KERNEL SIZE

THE CURRENT FRESH KCC FULL-BOOT KCORE+MRES TOTAL IS 14266 DECIMAL WORDS.
THE PERMANENT HIGH-WATER ADDRESS IS 033751 OCTAL (14313 DECIMAL).  THE CURRENT
SHRINK ACCEPTANCE LIMIT IS 14288 KCORE+MRES WORDS, SO THE 14K SHRINK TARGET IS
MET; FRESH LOGIN/EXEC ACCEPTANCE STILL HAS TO CLOSE THE PASS.  033777 IS THE
TEMPORARY 14K SHRINK-PASS LAST-ADDRESS CEILING, NOT THE ARCHITECTURAL HARD
LIMIT.  THE ARCHITECTURAL HARD LIMIT REMAINS BELOW 16K WORDS INCLUDING FIXED
RESIDENT AND IRREDUCIBLE SCRATCH KERNEL MEMORY.

OLD 11500, 11999, 12288, 12-KIWORD, 13312, AND 13-KIWORD TARGETS ARE HISTORICAL
ONLY.  GCC MAY PRODUCE A SMALLER IMAGE, BUT KCC IS THE ACCEPTANCE COMPILER.

## BOOT AND MULTIUSER USERSPACE

THE NORMAL BOOT ENTERS /SYSTEM/INIT AS PID 1.  INIT READS /CONFIG/INITTAB AND
STARTS LOGIN INSTANCES FOR THE CONFIGURED TERMINALS.  LOGIN AUTHENTICATES USING
/CONFIG/PASSWD, ESTABLISHES UID/GID, SESSION, PROCESS GROUP, CONTROLLING TTY,
HOME DIRECTORY, AND EXECUTES THE CONFIGURED SHELL, INITIALLY /SYSTEM/EXEC/DSH.

CTY, DCS0, AND GE0 MULTI-TERMINAL LOGIN/LOGOUT ACCEPTANCE TESTS EXIST.  INIT
SUPPORTS ONCE/RESPAWN AND REAPS CHILDREN.  THE OLD DSH-AS-INIT PATH IS NOT THE
CURRENT NORMAL BOOT MODEL.

CURRENT USERSPACE IS STILL BUILT WITH GCC/LIBGCC.  CONVERTING LIBC, INIT,
LOGIN, DSH, AND ALL EXISTING NORMAL USERSPACE TARGETS TO KCC IS THE IMMEDIATE
BLOCKER BEFORE FURTHER USERSPACE FEATURE WORK.

## REAL-TIME CLOCK AND PDP-6 SIMH HARDWARE

THE STANFORD PHIL PETIT PCLK AT DEVICE 0730 IS THE STANDARD DAIMOS WALL-CLOCK
SOURCE.  GETTIME READS A COMPACT, CHRONOLOGICALLY SORTABLE UTC TIME36 VALUE
DIRECTLY FROM PCLK.  SUPPORTED DATES ARE 2026-01-01 THROUGH 2125-12-31.  THE
60 HZ APR LINE CLOCK REMAINS THE INDEPENDENT MONOTONIC SCHEDULER/TIMER CLOCK.
THERE IS NO SERIAL RTC/RTCD STANDARD PATH.

THE CURRENT SIMH WORK ENABLES PCLK FOR PDP-6, DEFAULTS IT TO HOST-UTC REALTIME
MODE, RETAINS HISTORICAL MODE FOR WAITS COMPATIBILITY, EXPOSES THE ALREADY
IMPLEMENTED LPT DEVICE 0124 ON PDP-6, AND CORRECTS MTC BIT 0000002 TO ITS
HISTORICAL SEL UNIT-STATUS SEMANTICS.  SLAVE REVERSE INTERRUPTS AND PCLK
INTERRUPT DELIVERY REMAIN DEFERRED.

## PROCESS, VM, AND IPC

THE GENERIC VM BACKEND BOUNDARY IS IMPLEMENTED.  THE PDP-6 BACKEND USES
CONTIGUOUS USER EXTENTS, RELOCATION/PROTECTION, COMPACTION, AND WHOLE-IMAGE
SWAPPING WITHOUT LEAKING PDP-6 PHYSICAL-BASE DETAILS INTO GENERIC PROCESS/EXEC
CODE.

PROCESS GROUPS, SESSIONS, DOMAINS, CONTROLLING TERMINALS, FOREGROUND GROUPS,
STOP/CONTINUE, CHILD STATE REPORTING, AND NATIVE PROCESS EVENTS EXIST.  NO
SESSIONFS IS REQUIRED.

PIPES/FIFOS ARE IMPLEMENTED AS COMPACT TRANSIENT KERNEL OBJECTS WITH A
128-CHARACTER BUFFER, PIPE_BUF=128 ATOMIC WRITES, BLOCKING, EOF/BROKEN-PIPE,
REFERENCE MANAGEMENT, AND FILESYSTEM FIFO NAMES.  DSH DOES NOT YET USE THE
FULL PIPE/JOB-CONTROL FACILITY.

## VFS AND FILESYSTEMS

VFS PROVIDES COMMON DESCRIPTORS, PATH WALKING, MOUNT CROSSING, FILESYSTEM
DISPATCH, CREDENTIAL/MODE CHECKING, AND NORMAL FILE/FIFO OPERATIONS.  D6FS IS
THE NATIVE WRITABLE DISK FILESYSTEM.  DTFS PERSONALITIES SHARE A COMMON ENGINE;
TENEX/ITS PERSONALITIES ARE OPTIONAL TEST BUILDS RATHER THAN NORMAL-RESIDENT
ARCHITECTURE.

THE CURRENT TREE STILL HAS SEPARATE DEVFS/PROCFS/DOMAINFS IMPLEMENTATIONS AND
LEGACY /DEVICE, /PROC, AND /DOMAIN SPECIAL CASES.  THE ACCEPTED LATER DESIGN IS
ONE MONITORFS AT /MONITOR PLUS AN I/O-ONLY /DEV VIEW IMPLEMENTED BY THE SAME
CODE.  PROCESS INFORMATION STAYS UNDER /MONITOR; THERE IS NO FUTURE /PROC.

D6FS PERMISSIONS USE UID/GID/MODE WITH COMMON OWNER/GROUP/OTHER CHECKING.  UID
0 IS THE SIMPLE 0.9 ADMINISTRATIVE IDENTITY.  FILE_RENAME DESTINATION-DIRECTORY
PERMISSION CHECKING REQUIRES AN AUDIT AND REGRESSION TEST.

## STORAGE

DISK AND DRUM I/O IS ASYNCHRONOUS FROM THE PROCESS PERSPECTIVE.  THE STORAGE
ROUTER MODELS SHARED DCT OWNERSHIP; DSK270 HAS PER-UNIT QUEUES AND ELEVATOR
ORDERING.  FULL CROSS-SPINDLE MECHANICAL OVERLAP SELECTION AND DRUM ROTATIONAL
SCHEDULING ARE NOT YET COMPLETE.

THE CURRENT IMPLEMENTATION STILL STORES SEMANTIC SWAP/LOGSTORE REGION DATA IN
THE DISKSET LAYOUT AND EXPOSES REGION-SPECIFIC OPERATIONS.  THE ACCEPTED DESIGN
MOVES PERSISTENT RESERVATION OWNERSHIP INTO D6FS, HAS VFS REGISTER GENERIC RAW
RANGES, AND LEAVES PHYSICAL DISTRIBUTION/SCHEDULING/BAD-MEDIA MAPPING TO THE
LOWER DISKSET LAYER.  THIS MIGRATION IS PENDING.

## MEMORY/RESOURCE POLICY

PROCESS TABLE SIZE SCALES WITH AVAILABLE CORE.  PROCESS U-AREAS, USER VM, AND
PIPES ARE ALLOCATED ON DEMAND.  THE MM TRACKS ALLOCATED EXTENTS RATHER THAN A
LARGE PERMANENT FREE-OBJECT TABLE.  COMPACT 36-BIT/HALFWORD REPRESENTATIONS ARE
USED THROUGHOUT THE PROCESS, CREDENTIAL, VNODE, DESCRIPTOR, AND SCHEDULER STATE.
