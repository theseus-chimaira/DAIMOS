## KERNEL

THE KERNEL HAS A SMALL PERMANENT KCORE AND RECLAIMABLE KINIT REGIONS.  FIRST-USER BOOTSTRAP CODE IS RECLAIMED RATHER THAN RETAINED AS A PERMANENT DISPOSAL TRAMPOLINE.

THE PROCESS DESCRIPTOR IS 3 WORDS.  PROCESS TABLE SIZE IS SELECTED FROM 64, 128, OR 256 SLOTS ACCORDING TO AVAILABLE CORE.  256 IS THE ARCHITECTURAL SLOT LIMIT.  PID IS DERIVED FROM THE PROCESS-TABLE SLOT AND IS NOT STORED REDUNDANTLY IN THE DESCRIPTOR; THE LOW EIGHT BITS OF PROC.META ARE CURRENTLY FREE.

EACH ACTIVE PROCESS USES A STABLE 0420 OCTAL WORD EXECUTIVE AREA, 272 DECIMAL WORDS.  THE FIXED CONTEXT OCCUPIES 0000 THROUGH 0044, THE PACKED FD/SESSION/DOMAIN/EVENT CONTROL WORD IS 0045, CWD IS 0046, SIXTEEN TWO-WORD FILE DESCRIPTORS OCCUPY 0047 THROUGH 0106, AND THE PRIVATE KERNEL STACK OCCUPIES 0107 THROUGH 0416.  THE FINAL WORD, 0417, HOLDS NONRESIDENT SWAP-BACKING METADATA.  THE PRIVATE STACK IS THEREFORE 0310 OCTAL WORDS.  THE USER EXTENT MAY MOVE OR SWAP WHILE THE EXECUTIVE AREA REMAINS RESIDENT.

FILE DESCRIPTORS PRESERVE A FULL 36-BIT CHARACTER OFFSET.  THE OTHER WORD PACKS THE CANONICAL VNODE WITH FILE STATE IN BITS GUARANTEED ZERO BY THE CURRENT VNODE FIELD RANGES.  FILE_NEW_FD REJECTS A VNODE WHICH USES RESERVED STATE BITS.  PIPE ENDS USE THE SAME FILE-DESCRIPTOR MODEL.

THE SEPARATE PINNED RUNTIME IDLE/EXIT KERNEL STACK IS 0100 OCTAL WORDS, 64 DECIMAL WORDS.  LATE KINIT REMAINS ON ITS DISPOSABLE KINIT RESERVE STACK UNTIL ALL ALLOCATING/VFS BOOT WORK IS COMPLETE, THEN PUBLISHES THE PERMANENT IDLE STACK BEFORE THE NO-RETURN USER TRANSITION.  CURRENT TEST-ONLY WATERMARKS ARE 0245 OF 0310 OCTAL WORDS FOR A PROCESS PRIVATE KERNEL STACK AND 0023 OF 0060 OCTAL WORDS FOR THE IDLE/EXIT STACK TEST LIMIT.  PRODUCTION BUILDS CARRY NO WATERMARK STATE.

THE SCHEDULER SUPPORTS RUNNING, SLEEPING, STOPPED, AND ZOMBIE PROCESS STATES, EVENT WAITING, NICE VALUES, CPU PENALTY, SLEEP AGING, CLOCK PREEMPTION, SOFTWARE RESCHEDULING, AND RUNNABLE SWAPPED PROCESSES THROUGH SLOT-0 RESTORE SERVICE.  A FOUR-CLOCK USER QUANTUM MAKES THREE OF FOUR ORDINARY USER CLOCK TICKS O(1); RUNNABLE SELECTION WALKS AN INTRUSIVE RUN QUEUE STORED IN THE EXISTING SCHED RH, AND WHOLE-TABLE SLEEP-AGE MAINTENANCE OCCURS ONLY ON THE 64-CLOCK AGING BOUNDARY.

PROCESS CREATION, EXEC REPLACEMENT, WAIT/REAP, PROCESS HIERARCHY, SESSION AND DOMAIN STATE, CONTROLLING TTY STATE, PROCESS GROUPS, STOP/CONTINUE JOB CONTROL, AND ANONYMOUS/FIFO PIPE OPERATION ARE PRESENT.  THE 32K RUNTIME TESTS EXERCISE BLOCKED PIPE READERS AND WRITERS ACROSS REAL SWAP-OUT/SWAP-IN, AND STOPPED JOBS ACROSS SWAP AND CONTINUE/FOREGROUND RESUME.

## MEMORY MANAGEMENT

THE MEMORY MANAGER TRACKS AT MOST 20 ALLOCATED EXTENTS WITH TWO-WORD EXTENT DESCRIPTORS, SORTED BY PHYSICAL BASE.  FREE CORE IS NOT REPRESENTED BY EXTENT DESCRIPTORS; IT IS THE IMPLICIT GAP SPACE INSIDE AT MOST THREE PACKED ONE-WORD MANAGED ARENAS.  FRAGMENTATION THEREFORE CANNOT CONSUME ALLOCATION DESCRIPTORS, AND FREEING AN EXTENT DELETES ONE DESCRIPTOR INSTEAD OF CREATING OR COALESCING FREE DESCRIPTORS.

THE THREE-ARENA BOUND COVERS THE REAL KINIT TOPOLOGY: LOW RECLAIMABLE CORE, THE HIGH TAIL ABOVE THE KINIT RESERVE STACK, AND THE CURRENT CONTIGUOUS RUN OF DEAD MRES SOURCE PACKAGES.  ADJACENT RETURNED BOOT RANGES MERGE IMMEDIATELY.  THE 19 PACKED BOOT MRES IMAGES ARE PERMANENT KCORE+MRES STORAGE; AFTER INSTALLATION EACH IS COMMITTED OUT OF GENERAL MM BOOKKEEPING BY TRIMMING THE MANAGED ARENA EDGE, SO ITS PHYSICAL RANGE CANNOT BE REALLOCATED.

PROCESS AND DYNAMIC MOVABLE MODULE EXTENTS CAN BE COMPACTED.  PACKED BOOT MRES IS NOT MOVABLE OR RECLAIMABLE AND IS DELIBERATELY OUTSIDE THE GENERAL MM TABLE.  COMMON PDP-6 BLT COPY AND ZERO PATHS ARE USED FOR MOVEMENT AND INITIALIZATION.  THE ALLOCATED-ONLY MM REDESIGN REDUCES THE PERMANENT MM OBJECT BY 141 TEXT WORDS WHILE ADDING FOUR BSS WORDS FOR ARENA STATE, A NET 137-WORD PERMANENT REDUCTION, WITHOUT REDUCING THE 20 ALLOCATION-DESCRIPTOR CAPACITY.

PERMANENT MM TELEMETRY COUNTERS FOR COMPACTIONS, WORDS MOVED, AND ALLOCATION FAILURES ARE NOT PART OF MEMORY-MANAGER STATE.

## SWAP

PROCESS SWAPPING USES ONE RESIDENT RECORD WORD PER LOGICAL PROCESS SLOT.  WHILE A PROCESS IS RESIDENT, THAT WORD HOLDS ITS PACKED EXECUTABLE-BACKING HANDLE.  WHILE IT IS SWAPPED, THE SAME WORD HOLDS THE FIRST SWAP BLOCK AND FULL-SECTOR BLOCK COUNT; THE RESIDENT BACKING HANDLE IS TEMPORARILY RETAINED IN THE FINAL WORD OF THE PROCESS'S STABLE U-AREA.

THE CURRENT CORRECTNESS FORMAT WRITES THE COMPLETE ROUNDED USER EXTENT USING NORMAL 0200-WORD DISK SECTORS.  THERE IS NO PARTIAL TYPE-270 SWAP PATH, DISK HEADER BLOCK, OR 0200-WORD EXECUTIVE-STACK BOUNCE BUFFER.  CLEAN EXECUTABLE-TEXT RELOAD IS A DEFERRED OPTIMIZATION AND IS NOT PART OF THE CURRENT SWAP FORMAT.

VM DESTRUCTION OWNS SWAP-BACKING LIFETIME.  EXIT, FAILED EXEC, FAILED SWAP-IN, AND DISCARD RELEASE BACKING EXACTLY ONCE THROUGH THAT PATH.  SWAP RECLAIM CONTINUES UNTIL COMPACTION CAN ACTUALLY FORM THE REQUESTED ALIGNED EXTENT; IRREDUCIBLE PINNED-ISLAND FRAGMENTATION REMAINS DISTINCT FROM SIMPLE OUT-OF-MEMORY FAILURE.

THE PI SCHEDULER DOES NOT PERFORM DISK I/O.  A RUNNABLE SWAPPED WINNER TRANSFERS SERVICE TO PERMANENT SLOT 0, WHICH PERFORMS SYNCHRONOUS RESTORE AND RETURNS TO NORMAL SCHEDULING.  THE EXISTING SCHEDULER CURSOR CARRIES THE REQUEST/BUSY BIT, SO NO PER-PROCESS SWAP-SERVICE REQUEST OBJECT IS RESIDENT.

DSK RUNTIME REQUESTS USE A THREE-WORD TRANSIENT DESCRIPTOR CONTAINING DISK/BUFFER ADDRESS, AN EXPLICIT READ/WRITE OPERATION, AND COMPLETION EVENT/STATUS.  SLOT 0 DRAINS OLDER QUEUED WORK IN ORDER BEFORE ITS OWN SYNCHRONOUS SWAP REQUEST, SO DSK QUEUE PROGRESS DOES NOT DEPEND ON RESCHEDULING THE PROCESS WHICH COMPLETED THE PREVIOUS REQUEST.

SWAP KEEPS ONE LIVE WORD FOR USED SWAP BLOCKS.  TOTAL BLOCKS COME FROM DISKSET CONFIGURATION AND FREE BLOCKS ARE DERIVED AS TOTAL MINUS USED.  D6SET REPORTS TOTAL, USED, AND FREE SWAP BLOCKS WITHOUT PERMANENT LIFETIME I/O COUNTERS.

THE PRE-DSH SWAP/COMPACTION PLANNING CENSUS IS COMPLETE.  THE EXISTING TWO-VICTIM FRAGMENTATION REGRESSION REQUIRES TWO SWAP-OUTS AND PERFORMS TWO POST-SWAP COMPACTION PROBES; THE INTERMEDIATE FAILED PROBE MOVES ZERO WORDS.  WITH THE ALLOCATED-ONLY MM, EACH PROBE IS BOUNDED BY AT MOST 20 ALLOCATION DESCRIPTORS.  PRESELECTING AND WRITING EXTRA VICTIMS MERELY TO AVOID THAT SMALL BOUNDED PROBE WOULD RISK UNNECESSARY DISK I/O, SO THE CURRENT INCREMENTAL POLICY IS RETAINED: CHOOSE THE BEST VICTIM, SWAP IT, TEST/COMPACT, AND ONLY THEN SELECT ANOTHER VICTIM IF THE REQUEST STILL CANNOT BE SATISFIED.  THIS MINIMIZES SWAP I/O WHILE STILL CONTINUING ACROSS IRREDUCIBLE FRAGMENTATION.

## 2026-09-11 V30 MULTIPROCESS SENTINEL AND FULL RESIDENT SWEEP

SLEEP PROBE USES A PROCESS OUTSIDE THE NICE-ORDER COHORT SO I/O LATENCY CANNOT
INVALIDATE THE PRIORITY ASSERTION.

REJECTED.  THE SPECIAL CREATE FAST PATH USED A CALLER-CLOBBERED REGISTER FOR
