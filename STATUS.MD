## BOOT AND USERSPACE

THE PDP-6 DSK AND DRM BOOT PATHS USE THE SHARED 40-WORD RESUMABLE D6LZ36 CORE
AT 000060.  DSK/D6FS, DRM/D6FS, AND DTC/TSFS ROOT PATHS REACH /SYSTEM/INIT AND
LOGIN.  THE 32K LOWMEM PROFILE IS A SEPARATE ACCEPTANCE BUILD AND REACHES the
normal login/userland path.

NORMAL BOOT IS KINIT -> /SYSTEM/INIT -> LOGIN -> CONFIGURED SHELL.  INIT READS
/CONFIG/INITTAB; LOGIN USES /CONFIG/PASSWD AND ESTABLISHES CREDENTIALS,
SESSION/PROCESS-GROUP/TTY STATE, HOME, ENVIRONMENT, AND THE CONFIGURED SHELL.
DCS0/GE0 LOGIN/LOGOUT/RESPAWN TESTS PASS.  CTY INPUT INJECTION REMAINS A
HARNESS CAPABILITY TO IMPROVE, NOT A V0.9 BLOCKER.

RUN/EXEC USE THE BOUNDED COUNTED-SIXBIT STARTUP ABI.  NORMAL USERSPACE BUILDS
WITH KCC/DAS WITHOUT LIBGCC.

## VFS AND FILESYSTEMS

MONITORFS IS THE ONLY STATE FILESYSTEM.  /PROC ALIASES
/MONITOR/PROCESSES; /DEV PROJECTS DEVICE I/O ENDPOINTS; /DEVICE AND /DOMAIN
ARE NOT EXPOSED.

D6FS IS THE NATIVE WRITABLE FILESYSTEM.  MULTI-MOUNT, REMOUNT, RECOVERY,
UID/GID/MODE, MTIME, SEEK, CHOWN, RMDIR, RECLAIMABLE BLOCK CACHE, SWAP AND
LOGSTORE RESERVATIONS, DSK BACKING, AND DRM BACKING ARE IMPLEMENTED.

TSFS V1 IS IMPLEMENTED READ-ONLY.  TRANSIENT MOUNT SCANNING VALIDATES MEMBER,
TABLE, CHECKSUM, FILE, AND EXTENT METADATA; THE RESIDENT PROVIDER SUPPORTS
LOOKUP, READDIR, STAT, PARENT TRAVERSAL, MULTI-EXTENT/CROSS-MEMBER READS, AND
D6LZ36/STORED RESTART EXTENTS.

## STORAGE

DSK270 USES ITS BOUNDED PER-UNIT CYLINDER ELEVATOR.  DRM236 USES A MINIMAL
ONE-PENDING FIFO WITH NO ROTATIONAL OR TIMING ASSUMPTIONS.  THIS IS THE V0.9
MECHANICAL-SCHEDULING CLOSURE; ROTATIONAL SCHEDULING IS DEFERRED UNLESS REAL
HARDWARE OR A TIMING-ACCURATE MODEL PROVIDES USEFUL DATA.

BLOCKSET PROVIDES LOGICAL-TO-PHYSICAL MAPPING FOR MULTI-MEMBER SETS; SINGLE
MEMBER ROOTS BYPASS ITS MRES.  THE COMMON OPTIONAL BADMAP PACKAGE TRANSLATES
PHYSICAL DSK/DRM EXCEPTIONS BELOW FILESYSTEMS, swap, and LOGSTORE.  ONLINE
RETIREMENT AFTER RECOVERED DATA IS DEFERRED MAINTENANCE WORK.
