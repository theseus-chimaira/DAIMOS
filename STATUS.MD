## BOOT AND MULTIUSER USERSPACE

THE NORMAL BOOT ENTERS /SYSTEM/INIT AS PID 1.  INIT READS /CONFIG/INITTAB AND
STARTS LOGIN INSTANCES FOR THE CONFIGURED TERMINALS.  LOGIN AUTHENTICATES USING
/CONFIG/PASSWD, ESTABLISHES UID/GID, SESSION, PROCESS GROUP, CONTROLLING TTY,
HOME DIRECTORY, AND EXECUTES THE CONFIGURED SHELL, INITIALLY /SYSTEM/EXEC/DSH.

CTY, DCS0, AND GE0 MULTI-TERMINAL LOGIN/LOGOUT ACCEPTANCE TESTS EXIST.  INIT
SUPPORTS ONCE/RESPAWN AND REAPS CHILDREN.  THE OLD DSH-AS-INIT PATH IS NOT THE
CURRENT NORMAL BOOT MODEL.

CURRENT NORMAL USERSPACE BUILDS WITH KCC/DAS AND DOES NOT LINK LIBGCC.  RUN V2
AND EXEC V1 IMPLEMENT THE BOUNDED COUNTED-SIXBIT STARTUP ABI; CHILD ENTRY IS
AC1=ARGC, AC2=ARGV, AC3=ENVP.  INIT PASSES THE TERMINAL AS NORMAL ARGV[1].
A TEMPORARY, NON-COMMITTED AUTO-EXEC LOGIN PROBE BOOTED INIT V1 -> DSH V1 -> #.
SCRIPTED REAL TELNET SESSIONS NOW PASS LOGIN AS ROOT, DSH STARTUP, EXIT, AND
LOGIN RESPAWN ON BOTH DCS0 AND GE0 USING CRLF INPUT.  CTY INPUT-INJECTION
ACCEPTANCE REMAINS OPEN.

THE SYS_EXT_DUP2 DESCRIPTOR-REPLACEMENT OPERATION AND LIBC `dsys_dup2()` WRAPPER
ARE IMPLEMENTED.  TARGET-SIDE PROBING PASSED SELF-DUP, INVALID-SOURCE
ATOMICITY, AND REPLACEMENT OF AN OPEN TARGET WITH A PIPE END WHILE PRESERVING
THE PIPE REFERENCE AFTER THE ORIGINAL WRITER DESCRIPTOR WAS CLOSED.

THE MINIMAL TTY LINE DISCIPLINE IS IMPLEMENTED.  CANONICAL MODE PROVIDES CR/LF
LINE TERMINATION, PRINTABLE ECHO, BS/DEL ERASE, CTRL-U KILL, CTRL-D EOF, BOUNDED
120-CHARACTER INPUT, AND OPTIONAL CTRL-C/CTRL-Z FOREGROUND-PGRP EVENT GENERATION.
MODE BITS USE THE EXISTING TTY RECORD; 21 TTYS SHARE AN 11-WORD PACKED POINTER
TABLE, AND EACH ACTIVE CANONICAL LINE ALLOCATES 25 MANAGED-CORE WORDS.  LOGIN
USES COOKED MODE AND NO-ECHO PASSWORD INPUT; DSH SELECTS RAW/NO-ECHO/NO-SIGNALS.
PROCCTL 020-024 ARE RESERVED FOR UUO-077 EXTENSIONS; SETGID IS 025 AND TTY
GETMODE/SETMODE ARE 026/027.

## REAL-TIME CLOCK AND PDP-6 SIMH HARDWARE

THE STANFORD PHIL PETIT PCLK AT DEVICE 0730 IS THE STANDARD DAIMOS WALL-CLOCK
SOURCE.  GETTIME READS A COMPACT, CHRONOLOGICALLY SORTABLE UTC TIME36 VALUE
DIRECTLY FROM PCLK.  SUPPORTED DATES ARE 2026-01-01 THROUGH 2125-12-31.  THE
60 HZ APR LINE CLOCK REMAINS THE INDEPENDENT MONOTONIC SCHEDULER/TIMER CLOCK.
THERE IS NO SERIAL RTC/RTCD STANDARD PATH.

THE CURRENT SIMH WORK ENABLES PCLK FOR PDP-6, DEFAULTS IT TO HOST-UTC REALTIME
MODE, AND THE GENERATED DAIMOS BOOT CONFIGURATION NOW EXPLICITLY ENABLES PCLK
AND SELECTS A MAKE-CONFIGURABLE MODE (`REALTIME` BY DEFAULT), RETAINS
HISTORICAL MODE FOR WAITS COMPATIBILITY, EXPOSES THE ALREADY
IMPLEMENTED LPT DEVICE 0124 ON PDP-6, AND CORRECTS MTC BIT 0000002 TO ITS
HISTORICAL SEL UNIT-STATUS SEMANTICS.  SLAVE REVERSE INTERRUPTS AND PCLK
INTERRUPT DELIVERY REMAIN DEFERRED.

### COMPACTOR / RELOCATOR

THE MM COMPACTOR NOW RELOCATES AN EXISTING EXTENT DIRECTLY.  ITS FIT SEARCH
TEMPORARILY TREATS THE SOURCE DESCRIPTOR AS FREE, SO A DESTINATION MAY OVERLAP
THE OLD IMAGE OR LIVE IN A DIFFERENT MANAGED ARENA WITHOUT ALLOCATING A SECOND
FULL IMAGE OR A SECOND EXTENT DESCRIPTOR.  MODULES PACK LOW; PROCESS IMAGES PACK
HIGH.  `fs_move_words()` PROVIDES OVERLAP-SAFE WORD MOVEMENT.  PI IS SUPPRESSED
WHILE MODULE/PROCESS OWNER STATE AND THE MM DESCRIPTOR ARE REPUBLISHED.  CLEAN
D6FS CACHE RECLAIM NOW PRECEDES COMPACTION, AND PROCESS SWAP FOLLOWS IF DIRECT
RELOCATION STILL CANNOT CREATE THE REQUESTED EXTENT.

HOST MM REGRESSION VALIDATION COVERS MULTI-MOVE PROCESS STATE, PINNED AND
MAPPING-HELD ISLANDS, MODULE RELOCATION/BINDING RETARGETING, A MODULE WITH A
LOWER HOLE SMALLER THAN ITS IMAGE, AND THE FORMER TWO-02000-HOLE/04000-PROCESS
CASE WHICH NOW SUCCEEDS BY AN OVERLAPPING UPWARD SLIDE INSTEAD OF SWAPPING.
THE CURRENT PDP-6 IMAGE ALSO BOOTS THROUGH INIT TO LOGIN.  PERMANENT REGRESSION
INTEGRATION BELONGS IN PDP-C-TESTKIT WHEN THE CURRENT TEST TREE IS AVAILABLE.

## VFS AND FILESYSTEMS

VFS PROVIDES COMMON DESCRIPTORS, PATH WALKING, MOUNT CROSSING, FILESYSTEM
DISPATCH, CREDENTIAL/MODE CHECKING, AND NORMAL FILE/FIFO OPERATIONS.  D6FS IS
THE NATIVE WRITABLE DISK FILESYSTEM.  DTFS PERSONALITIES SHARE A COMMON ENGINE;
TENEX/ITS PERSONALITIES ARE OPTIONAL TEST BUILDS RATHER THAN NORMAL-RESIDENT
ARCHITECTURE.

MONITORFS IS THE ONLY PROCESS/DOMAIN/DEVICE STATE FILESYSTEM.  /MONITOR ENUMERATES
PROCESSES, DOMAINS, AND DEVICES; /PROC ALIASES /MONITOR/PROCESSES AND CONTAINS
ONLY PROCESS OBJECTS; /DEV FLATTENS EACH /MONITOR/DEVICES/NAME/IO ENDPOINT TO
/DEV/NAME.  /DEVICE AND /DOMAIN ARE REJECTED.  TARGET TESTS COVER LOOKUP/STAT,
DIRECTORY ENUMERATION, CANONICAL GETCWD/PARENT TRAVERSAL, AND DEVICE I/O VIEWS.

D6FS NOW EXPOSES ITS EXISTING 36-BIT MTIME THROUGH VFS STAT AND UPDATES IT ON
FILE CONTENT/LENGTH AND DIRECTORY-ENTRY MUTATIONS.  DATE DECODES PCLK TIME36;
TOUCH USES GETTIME/UTIME.  SEEK SET/CUR/END USES THE EXISTING 36-BIT DESCRIPTOR
CHARACTER OFFSET WITHOUT DESCRIPTOR GROWTH.  CHOWN AND RMDIR ARE NATIVE THIN
OPERATIONS.  TARGET VALIDATION COVERED SEEK, OWNERSHIP CHANGES, NON-EMPTY RMDIR
REJECTION, EMPTY RMDIR SUCCESS, AND AUTOMATIC WRITE MTIME.  THE SAME TEST PASS
FOUND AND FIXED D6FS FINAL-WORD TAIL GROWTH FOR SUB-WORD FILE EXTENSION.

D6FS PERMISSIONS USE UID/GID/MODE WITH COMMON OWNER/GROUP/OTHER CHECKING.  UID
0 IS THE SIMPLE 0.9 ADMINISTRATIVE IDENTITY.  FILE_RENAME NOW CHECKS ACCESS ON
THE RESOLVED SOURCE AND DESTINATION PARENT DIRECTORIES; THE PREVIOUS
UNINITIALIZED DESTINATION-SLOT CHECK IS FIXED.  PERMANENT REGRESSION COVERAGE
REMAINS TESTKIT WORK.

## STORAGE

DISK AND DRUM I/O IS ASYNCHRONOUS FROM THE PROCESS PERSPECTIVE.  THE STORAGE
ROUTER MODELS SHARED DCT OWNERSHIP; DSK270 HAS PER-UNIT QUEUES AND ELEVATOR
ORDERING.  FULL CROSS-SPINDLE MECHANICAL OVERLAP SELECTION AND DRUM ROTATIONAL
SCHEDULING ARE NOT YET COMPLETE.

BLOCKSET IS A GENERIC LOGICAL-TO-PHYSICAL BLOCK MAPPER.  A SINGLE DSK ROOT
BYPASSES ITS MRES ENTIRELY; MULTI-MEMBER ROOTS INSTALL A 41-WORD ROOT PACKAGE.
SEMANTIC OWNERSHIP IS NOT ENCODED IN BLOCKSET.  D6FS PERSISTS SWAP AND LOGSTORE
RESERVATIONS, AND VFS TRACKS THEIR TYPED PER-MOUNT OWNERSHIP.  SWAP AND
LOGSTORE OWNERSHIP ARE INDEPENDENTLY RELEASABLE AND EACH RESOURCE IS EXCLUSIVE
SYSTEM-WIDE.

D6FS MULTI-MOUNT, MOUNT-OWNED 17-WORD READERS, GENERIC PER-MOUNT BACKING,
REMOUNT, RECOVERY, MAINTENANCE, AND RESERVATION ACTIVATION ARE IMPLEMENTED.
D6FS-ON-DRM THROUGH THE EXISTING BACKING/BLOCKSET INTERFACE REMAINS OPEN.

TSFS MEMBER DISCOVERY, CHECKSUMS, AND TABLE VALIDATION RUN TRANSIENTLY.
MOUNT.TSFS PASSES COMPACT VALIDATED STATE TO THE RESIDENT READ-ONLY PROVIDER.
LOOKUP, READDIR, STAT, PARENT TRAVERSAL, AND ONE CONTIGUOUS TAPE-LOCAL EXTENT
PER REGULAR FILE ARE IMPLEMENTED.  MULTI-EXTENT, CROSS-MEMBER, AND
D6LZ36-COMPRESSED REGULAR-FILE PAYLOADS REMAIN OPEN.

BAD-MEDIA RUNTIME TRANSLATION IS IMPLEMENTED AS THE OPTIONAL MOVABLE BADMAP
PACKAGE SHARED BY DSK270 AND DRM236 STORAGE SETS.  ONE 36-BIT WORD MAPS AN
18-BIT SOURCE PHYSICAL LOCATOR TO AN 18-BIT SPARE LOCATOR; CLEAN MEDIA INSTALL
NO BADMAP PACKAGE OR EXCEPTION TABLE.  THE SAME TRANSLATOR SITS BELOW D6FS,
LOGSTORE, AND THE RAW SWAP-TAIL NAMESPACE.  DEVICE-SPECIFIC RETRY AND
MECHANICAL SCHEDULING REMAIN IN THE LEAF DRIVERS; ONLINE RETIREMENT AFTER
RECOVERED DATA REMAINS OPEN.
