# K10-K11 v1975: forward overlap component and admission-format audit

Parent DAIMOS `3bddddd8` (v1974). K01-K09 and the scoped K17 native
KA10 functional gates are closed. K10-K16 remain optional. No mode3
production activation, fixed KCORE or installed MRES link change.

## K10: proposed DXR admission (not yet implemented)

DXR header word 1 RH is fully occupied: BSS 0077777, COMPRESSED
0100000, PURE 0200000 and RT_REQUIRED 0400000. Do not steal a BSS bit.
The TX2 extension word LH is the uncompressed text count; the current
initialized-image bound is 0300000, so bit 0400000 in this LH is unused.
A candidate COMPRESSIBLE_MUTABLE flag there preserves BSS, payload
compression, entry, relocation and header length. A new loader must
accept unmarked DXR1/DXR2; an old loader would reject a marked DXR2
because its text count exceeds the initialized image. This is backward
compatibility for new readers, not old-reader forward compatibility.
Do not emit marked files until all required readers are updated.

Source audit: `exec_load.s` and `exec_image_common_v1386.s` each validate
TX2 and must agree on flags and masked text count. `tools/host/mkinitfs0.c`
validates both plain and compressed DXR2; host and native dlink produce
TX2; d6block-v1452 copies the original extension while setting payload
COMPRESSED. Audit the remaining reader/producer and install paths.
Admission is a property of the validated current executable (or an
explicit privileged policy), never a user-written runtime state bit.
Legacy/unmarked images, raw XIP, RT exclusion and ordinary disk swap
must keep their original contracts. Do not interpret PURE or payload
COMPRESSED as mutable eligibility. Current mode3 only supports a
validated PURE-backed suffix; other images still have no mode3 path.

Candidate zero-extra-word runtime representation: credential bit 31
outside UID9/GID9/UMASK9 and mount/provider bits 27..30; SIDL staging
RH bit 5 if its complete lifetime is proved. `proc_pure_attach.c`,
`proc_run.s`, `exec_lowmem_pdp6.s` and `vm_pdp6_swap.c` currently
transport exactly four backing-identity bits. Widening that transaction
needs a full credential/slot/failure audit, not an isolated mask change.
No extra process word, no new privileged syscall and no runtime VFS
read in reclaim. EXEC must replace eligibility on commit, preserve old
eligibility on rollback, and clear it on detach/reuse. No active FORK
entry was found in the current kernel; any supported future fork must
inherit the current executable eligibility without inheriting mode3.
K10 is OPEN: header, linker, loader, credential and privilege tests
have not been implemented. These are candidate encodings, not a new ABI.

## K11: source-linked bounded forward codec (partial PASS)

`proc_pure_bitmap_overlap_v1975.[ch]` provides a read-only exact-size
planner and bounded encode/decode around the existing 30-word v1451
assembler. Each prospective store is checked against the exact unread
input interval. Encoder clears the mask before its first input load,
then reads each nonzero word before storing it. Decoder reads a mask,
but clears each destination before reading the corresponding literal.
Checking that literal after the store would miss a destructive overlap.
The plan verifies actual input data, not just endpoint ordering.
Nonshrinking output, inadequate capacity, unsafe overlap, malformed
canonical masks/zero literals/truncation/trailing data are refused.
No destination or input write occurs on refusal; count remains unchanged.
The caller must hold stable, exclusive spans and an independent count
cell throughout preflight and execution. This leaf cannot establish MM
ownership or publish a storage state. No additional scratch array.

Native PDP-6, KCC 89c036e (v59g): 612 matrix cases, 269 successful
encodes/decodes, 199 unsafe-overlap refusals, 144 nonshrinking encodes.
Separate focused capacity/corruption/overlap cases PASS; all 378 encode
requests also execute the independent read-only planner. Entire test
arena checked; independent encoder and decoder hazard-check mutants
execute and fail (exit 2 and 5). Existing v1660 decoder component and
exact-consumption mutant PASS with the installed corrected compiler.
Testkit `944b19b`; installed replay evidence
`$TMPDIR/daimos-bitmap-overlap-v1975.5M0mWA` and
`$TMPDIR/daimos-bitmap-decode-v1660.KkQmLi`.
Exact native DOBJ counts: v1975 wrapper 286 TEXT, 0 DATA, 0 BSS;
v1451 codec 30 TEXT, 0 DATA, 0 BSS. This is not an installed link-size
measurement. Reuse/replace existing validation when integrating rather
than accumulating parallel wrappers. No reverse traversal implemented.

KCC static absolute word-pointer constructor defect surfaced in the
original fixture. The fix is KCC `89c036e`, not a DAS compatibility
shim; the old compiler fails the dedicated regression, new -O/-O0
native execution passes. Installed at PDP10_PREFIX/bin/kcc.

## K12-K16: unchanged gates and preferred first transaction

Do not call v1975 with raw physical addresses inferred from a process
slot. Prove a sole, pinned full original APR owner with the current
v1922 MM-table and lifecycle guards before borrowing its reconstructible
prefix. If the entire encoded stream fits inside the still-owned prefix,
encoding can preserve the original RAW suffix until atomic MM commit.
If the stream overlaps RAW, a safe forward write schedule alone is not
a rollback proof: the authoritative stream can change during encoding.
Require a nonfailing/recoverable ownership commit before allowing that
case in live DROP. If unsafe, fall back to RAW; do not allocate another
full mutable image or use the shared VFS workspace without a lease.

Reverse decode/restore from end, overlapping FULL APR destination,
foreign MM owner and failure/reply-loss handling remain open. The
v1663 disjoint candidate is not a production replacement for v1918+
owner and recovery guarantees. Keep fixed VM destroy refusal, mode3
OFF and the mandatory RAW/disk paths unchanged until accepted.
