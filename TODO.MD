# DAIMOS VERSION 0.9 ROADMAP

THIS FILE DEFINES THE WORK REQUIRED TO REACH VERSION 0.9.  IT IS A ROADMAP, NOT A CURRENT-STATE LOG.

## 1. FREEZE THE KERNEL ABI FOUNDATION

- COMPLETE THE USER UUO ABI AND DIRECT C ENTRY MODEL.
- KEEP KCC AND GCC CALLING CONVENTIONS ABI COMPATIBLE.
- REMOVE AVOIDABLE WRAPPER CALLS WHERE A DIRECT UUO IS SMALLER AND FAST ENOUGH.
- KEEP EXECUTIVE INTERNAL SERVICE CALLS ON DIRECT REGISTER BRIDGES UNLESS MEASUREMENT PROVES A DIFFERENT ABI SMALLER AFTER TRAP COST IS INCLUDED.
- KEEP COMMON VFS, MRES, DEVICE, AND SERVICE DISPATCH PATHS SHARED.
- COMPLETE A NEW CALL AND REFERENCE CENSUS AFTER ABI CHANGES SETTLE.

## 2. COMPLETE PROCESS AND EXECUTION SEMANTICS

- COMPLETE PROCESS CREATION NEEDED FOR A REAL MULTIUSER SYSTEM.
- COMPLETE WAIT AND CHILD REAPING SEMANTICS.
- COMPLETE EXEC REPLACEMENT SEMANTICS AND FAILURE CLEANUP.
- COMPLETE SIGNAL OR MINIMAL ASYNCHRONOUS PROCESS CONTROL REQUIRED BY THE USER ENVIRONMENT.
- VERIFY SCHEDULER FAIRNESS, NICE HANDLING, SLEEP AND WAKEUP, STOP, EXIT, AND SWAPPED SLEEPERS.
- VERIFY THAT STABLE EXECUTIVE AREAS NEVER RETAIN POINTERS INTO MOVABLE USER EXTENTS.

## 3. IMPLEMENT PIPES

- ADD A SMALL PIPE OBJECT WITH BOUNDED BUFFERING.
- INTEGRATE PIPE ENDS WITH THE EXISTING FILE DESCRIPTOR MODEL.
- IMPLEMENT BLOCKING READ AND WRITE WITH CORRECT WAKEUPS.
- IMPLEMENT END-OF-FILE AND BROKEN-PIPE SEMANTICS.
- SUPPORT DSH PIPELINES.
- TEST PIPE PRESSURE, CLOSE ORDER, PROCESS EXIT, AND SWAP WHILE BLOCKED.

## 4. FINISH MEMORY MANAGEMENT FOR MULTIUSER LOAD

- VERIFY COMPACTION OF PROCESSES AND MOVABLE MODULES UNDER FRAGMENTATION.
- KEEP THE KERNEL PROTECTED FROM COMPACTION.
- KEEP MODULE AND PROCESS MOVES PHYSICALLY CORRECT WITHOUT ASSUMING A HARDWARE PAGER.
- COMPLETE TEXT-ONLY SWAP SEMANTICS FOR CLEAN EXECUTABLE TEXT.
- PRESERVE DIRTY OR IMPURE PROCESS STATE ON SWAP.
- EXPOSE CURRENT SWAP CAPACITY, USED BLOCKS, AND FREE BLOCKS WITHOUT LIFETIME READ OR WRITE ACCOUNTING.
- VERIFY SWAP SLOT REUSE, PROCESS EXIT WHILE SWAPPED, EXEC AFTER SWAP-IN, AND OUT-OF-SWAP FAILURE PATHS.
- DECIDE WHETHER USERSPACE OVERLAYS ARE REQUIRED BEFORE THE KCC TRANSITION.
- IF REQUIRED, IMPLEMENT USERSPACE OVERLAYS BEFORE THE KCC TRANSITION.

## 5. COMPLETE CORE FILE AND VFS SEMANTICS

- VERIFY OPEN, CLOSE, READ, WRITE, SEEK, STAT, CHDIR, DIRECTORY WALK, CREATE, TRUNCATE, APPEND, RENAME, AND REMOVE SEMANTICS.
- COMPLETE MOUNT AND UNMOUNT SEMANTICS NEEDED BY THE USER ENVIRONMENT.
- KEEP TRANSFER WORD HANDLING COMMON ACROSS FILESYSTEMS.
- COMPLETE D6FS RELIABILITY TESTS FOR NORMAL WRITABLE OPERATION.
- COMPLETE DTFS NATIVE, TENEX, AND ITS PERSONALITY TESTS WITHOUT DUPLICATING COMMON RESIDENT LOGIC.
- VERIFY DEVICEFS, PROCFS, MEMFS, INITFS, D6FS, AND DTFS INTERACTION THROUGH COMMON VFS PATHS.
- VERIFY CLEAN RECOVERY FROM STORAGE ERRORS.

## 6. COMPLETE DSH FOR DAILY USE

- COMPLETE PIPELINE EXECUTION AFTER PIPES EXIST.
- COMPLETE REDIRECTION AND FILE DESCRIPTOR LIFETIME RULES.
- COMPLETE BUILTINS REQUIRED FOR BOOTSTRAP AND SYSTEM ADMINISTRATION.
- KEEP PARSING SMALL AND PURPOSEFUL.
- ADD ONLY FEATURES REQUIRED BY THE VERSION 0.9 USER ENVIRONMENT.

## 7. BUILD THE SELF-HOSTING TOOL BASE

IMPLEMENT OR PORT THE MINIMUM DEPENDENCIES REQUIRED FOR:

- DSH.
- MAKE.
- DAS.
- KCC.

ALSO PROVIDE THE BASIC FILE, TEXT, COPY, MOVE, REMOVE, DIRECTORY, AND DIAGNOSTIC UTILITIES REQUIRED TO BUILD AND MAINTAIN THE SYSTEM ON DAIMOS.

## 8. TEMPORARY KCC COMPILER TRANSITION

- VERIFY KCC AND GCC ABI INTEROPERABILITY WITH MIXED OBJECTS.
- BUILD THE KERNEL AND USER COMPONENTS WHICH KCC CAN ALREADY COMPILE.
- SWITCH THE MAIN DAIMOS COMPILER TO KCC TEMPORARILY BEFORE THE FULL KCC PORT IS FINISHED.
- USE THIS TRANSITION TO FIND ABI AND CODE-GENERATION BUGS EARLY.
- FIX COMPILER OR ASSEMBLER BUGS AT THEIR SOURCE.  DO NOT ADD TARGET WORKAROUNDS.

## 9. PORT KCC FULLY

- PORT THE REQUIRED KCC FRONT END, BACK END, LIBRARY SUPPORT, AND BUILD RULES.
- BUILD KCC UNDER DAIMOS.
- COMPILE REPRESENTATIVE SYSTEM AND USER PROGRAMS WITH THE NATIVE KCC.
- VERIFY THAT KCC OUTPUT LINKS WITH GCC OUTPUT AND WITH DAS ASSEMBLY.
- REBUILD DAIMOS COMPONENTS WITH THE NATIVE TOOLCHAIN WHERE PRACTICAL.

## 10. PORT MAKE AND DAS FOR SELF HOSTING

- BUILD DAS NATIVELY.
- BUILD MAKE NATIVELY.
- REMOVE HOST-ONLY ASSUMPTIONS FROM THEIR DAIMOS BUILD PATHS.
- VERIFY A COMPLETE EDIT, ASSEMBLE OR COMPILE, LINK, AND INSTALL CYCLE ON DAIMOS.

## 11. PORT THE WORKING USER TOOLSET

- PROVIDE A PRACTICAL EDITOR.
- PROVIDE FILE AND DIRECTORY UTILITIES.
- PROVIDE TEXT FILTERS NEEDED BY BUILDS AND ADMINISTRATION.
- PROVIDE SYSTEM INSPECTION UTILITIES FOR PROCESSES, MEMORY, FILESYSTEMS, DEVICES, AND SWAP.
- KEEP FEATURES SMALL ENOUGH FOR PDP-6 AND SMALL PDP-10 MEMORY LIMITS.

## 12. ADD THE RUNTIME MODULE LOADER

THIS IS DELIBERATELY AFTER THE INITIAL USER ENVIRONMENT AND SELF-HOSTING PORT.

- LOAD MOVABLE MODULES INTO MANAGED CORE.
- APPLY RELOCATION AND SERVICE BINDINGS.
- COMPACT MOVABLE MODULES WITH THE MEMORY MANAGER.
- LOAD SLOW DEVICE SUPPORT ON DEMAND WHERE APPROPRIATE.
- AUTO-UNLOAD AUTOMATICALLY LOADED MODULES AFTER THEIR LAST HANDLE IS RELEASED.
- KEEP MANUALLY LOADED MODULES RESIDENT UNTIL EXPLICITLY UNLOADED.
- VERIFY FAILURE AT EVERY LOAD, RELOCATION, BIND, MOVE, AND UNLOAD BOUNDARY.

## 13. RESIDENT-MEMORY FINAL SWEEP

AFTER FUNCTIONALITY IS COMPLETE:

- RUN A NEW KCORE CALL AND REFERENCE CENSUS.
- PACK PROCESS AND MM REPRESENTATIONS WHERE THIS DOES NOT DAMAGE SPEED OR CLARITY.
- REMOVE DUPLICATED PERMANENT STATE WHICH CAN BE DERIVED CHEAPLY.
- SHARE C-LEVEL COLD AND ERROR TAILS.
- MOVE ALL REMAINING ONE-SHOT BOOT CODE INTO RECLAIMABLE INITIALIZATION SPACE.
- RECHECK INTERNAL SERVICE ABI COSTS WITH ACTUAL LINKED SIZE AND TRAP COST BEFORE CHANGING THE DIRECT REGISTER BRIDGES.
- USE SELECTIVE ASSEMBLY ONLY AFTER STRUCTURAL C SAVINGS ARE EXHAUSTED.
- PERFORM A WHOLE-KERNEL RESIDENT WORD SWEEP.

THE FULL MULTIUSER VERSION 0.9 KERNEL MUST REMAIN BELOW 12K WORDS OF PERMANENT RESIDENT CORE.

## 14. PERFORMANCE AND STRESS VALIDATION

- RUN MULTIUSER SCHEDULER STRESS.
- RUN PIPE AND FILE DESCRIPTOR STRESS.
- RUN MEMORY FRAGMENTATION AND COMPACTION STRESS.
- RUN SWAP-IN AND SWAP-OUT STRESS WITH CLEAN AND IMPURE EXECUTABLES.
- RUN D6FS AND DTFS MUTATION AND RECOVERY TESTS.
- RUN STORAGE ERROR INJECTION.
- RUN MODULE MOVE AND UNLOAD STRESS AFTER THE LOADER EXISTS.
- MEASURE INTERACTIVE LATENCY ON PDP-6 CLASS HARDWARE OR SIMULATION.
- FIX ASSEMBLER AND COMPILER FAILURES BEFORE LOWER-PRIORITY OPTIMIZATION ISSUES.

## 15. VERSION 0.9 RELEASE GATE

VERSION 0.9 REQUIRES ALL OF THE FOLLOWING:

- STABLE MULTIUSER PROCESS EXECUTION.
- WORKING PIPES.
- PRACTICAL DSH.
- RELIABLE D6FS AND REQUIRED DTFS PERSONALITIES.
- WORKING COMPACTION AND TEXT-AWARE SWAPPING.
- SELF-HOSTED DAS, MAKE, AND KCC TOOL PATH.
- A PRACTICAL NATIVE USER TOOLSET.
- RUNTIME MODULE LOADING IF REQUIRED BY THE VERSION 0.9 HARDWARE PROFILE.
- KCC AND GCC ABI COMPATIBILITY.
- CLEAN REGRESSION TEST RESULTS.
- NO KNOWN COMPILER OR ASSEMBLER BUG AFFECTING GENERATED SYSTEM CODE.
- PERMANENT RESIDENT KERNEL BELOW 12K WORDS.
