## 4. COMPLETE THE DSH PLATFORM PREREQUISITES

THESE ITEMS PRECEDE THE SUBSTANTIAL DSH PORT.  THE STARTUP ABI, DESCRIPTOR
REPLACEMENT, AND TTY MODE ARE SEMANTIC BLOCKERS.  THE D6FS CACHE IS A DELIBERATE
PERFORMANCE PREREQUISITE FOR THE CHOSEN DEVELOPMENT ORDER.

### 4.1 PROGRAM-STARTUP ABI

- IMPLEMENT ONE VERSIONED BOUNDED RUN/EXEC STARTUP ABI.  PRESERVE CURRENT PGRP
  AND FD-MAP SEMANTICS.
- USE ONE SELF-CONTAINED BOUNDED USER LAUNCH BLOCK WITH COUNTED SIXBIT
  ARGUMENT/ENVIRONMENT RECORDS, NOT A GRAPH OF UNTRUSTED USER POINTERS.
- BUILD THE CHILD/REPLACEMENT IMAGE WITH AC1=ARGC, AC2=ARGV, AC3=ENVP.  SHARE
  ONE VALIDATED MARSHAL/COPY BUILDER BETWEEN RUN AND EXEC.
- DEFINE THE CRT0/LIBC ENTRY CONTRACT AT THE SAME TIME.  ENVIRONMENT RECORDS
  USE NAME=VALUE.
- REMOVE THE CURRENT PRIVATE INIT->LOGIN AC1=TTY CONVENTION.  INIT SHALL START
  EACH INITTAB SERVICE WITH NORMAL ARGV, INCLUDING THE CONFIGURED TTY ID AS
  ARGV[1]; LOGIN AND OTHER TTY SERVICES SHALL PARSE THAT ARGUMENT AND ATTACH
  THE CONFIGURED TTY THROUGH THE NORMAL PROCESS-CONTROL INTERFACE.
- ADD HOST AND TARGET TESTS FOR ZERO/MAXIMUM ARGUMENTS, EMPTY ARGUMENTS,
  ENVIRONMENT INHERITANCE/REPLACEMENT, MALFORMED BOUNDS, FD MAPS, PGRP MODES,
  INIT/LOGIN TTY ARGUMENT PASSING, RUN FAILURE, AND EXEC REPLACEMENT.

### 4.2 DUP2-EQUIVALENT DESCRIPTOR REPLACEMENT

- ADD A SMALL DESCRIPTOR REPLACEMENT OPERATION AND LIBC WRAPPER BEFORE DSH
  REDIRECTION.  RUN FD MAPS HANDLE CHILD SETUP; BUILTINS, FUNCTIONS, SOURCE,
  AND COMPOUND COMMANDS NEED TEMPORARY REDIRECTION IN THE SHELL PROCESS WITHOUT
  FRAGILE CLOSE/DUP LOOPS.
- TEST SELF-DUPLICATION, REPLACEMENT OF AN OPEN TARGET, INVALID DESCRIPTORS,
  PIPE ENDS, FILE OFFSETS/OPEN-FILE SHARING, AND ERROR ATOMICITY.

### 4.3 MINIMAL TTY LINE DISCIPLINE

- ADD A SMALL PER-TTY CANONICAL/ECHO MODE WHILE RETAINING RAW MODE FOR DSH
  INTERACTIVE EDITING, ELVIS, AND SIMILAR PROGRAMS.
- COOKED MODE SHALL PROVIDE CR/LF NORMALIZATION, ECHO, BS/DEL ERASE, CTRL-U
  LINE KILL, CTRL-D EOF, AND BOUNDED INPUT.
- ADD ONE SMALL SIGNAL-GENERATION MODE BIT ALONGSIDE CANONICAL/ECHO.  DSH
  MUST RUN ITS OWN RAW EDITOR WITH TERMINAL-GENERATED CTRL-C/CTRL-Z DISABLED;
  ORDINARY FOREGROUND JOBS NORMALLY ENABLE THEM.  THIS IS REQUIRED SO CTRL-C AT
  THE DSH PROMPT DOES NOT KILL THE SHELL.
- KEEP CTRL-C/CTRL-Z GENERATION IN THE KERNEL WHEN THAT MODE BIT IS ENABLED; DO
  NOT ADD A FULL TERMIOS LAYER.
- PROVIDE A SMALL TTY-IDENTITY QUERY SUFFICIENT FOR LIBC ISATTY AND FOR DSH TO
  DECIDE WHETHER FD 0 IS ITS CONTROLLING TERMINAL.
- PROVIDE A COMPACT GET/SET MODE ABI.  DSH MUST SAVE ITS OWN RAW/NO-ECHO MODE,
  GIVE ORDINARY FOREGROUND JOBS CANONICAL/ECHO MODE, SAVE A STOPPED JOB'S MODE,
  RESTORE IT ON FG, AND RESTORE THE SHELL MODE WHEN THE JOB STOPS OR EXITS.
- KEEP FIXED PER-TTY STATE TINY.  ACQUIRE BOUNDED PARTIAL-LINE STORAGE ONLY IN
  SLEEPABLE READER CONTEXT AND FREE IT AFTER THE RECORD/EOF HAS DRAINED OR THE
  MODE IS RESET.
- MEASURE THE RESIDENT WORD COST AGAINST THE V1 COOKED-CONSOLE REFERENCE AND
  HAND-OPTIMIZE IF GENERATED CODE IS DISPROPORTIONATE.
